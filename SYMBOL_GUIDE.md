## 🔍 Search Tips

### 1. **Try Multiple Formats**
If one doesn't work, try alternatives:
- `JIO` → `JIOFIN` → `JIOFIN.NS`
- `GOLD` → `XAUUSD` → `GC=F`

### 2. **Common Patterns**

**Indian Stocks**: Usually just the company name
- Example: `RELIANCE`, `TCS`, `INFY`

**US Stocks**: Ticker symbol
- Example: `AAPL`, `TSLA`, `MSFT`

**Crypto**: Symbol + `-USD`
- Example: `BTC-USD`, `ETH-USD`

**Forex**: Two currency codes together
- Example: `EURUSD`, `GBPUSD`

**Commodities**: Usually starts with X for metals
- Example: `XAUUSD` (Gold), `XAGUSD` (Silver)

### 3. **Case Insensitive**
You can type in any case:
- `aapl` = `AAPL` = `Aapl`

### 4. **Use Suggestions**
The search box shows suggestions as you type - click on them!

## ❌ Common Errors & Solutions

### "No data found for 'JIO'"
**Solution**: Use `JIOFIN` or just `JIO` (now supported!)

### "No data found for 'GOLD'"
**Solution**: Use `XAUUSD` or `GC=F`

### "No data found for 'OIL'"
**Solution**: Use `XTIUSD` or `CL=F`

### "No data found for 'BITCOIN'"
**Solution**: Use `BTC-USD` or `BTCUSD`

### "No data found for 'NIFTY'"
**Solution**: Use `NIFTY50` or `^NSEI`
